# Transferencia a Floot

`balcon-floot.zip` contiene el código del piloto web y la base SwiftUI anterior, sus recursos, configuración pública de Supabase, esquema, pruebas y las instrucciones `FLOOT-IMPORTAR.md`.

La guía también está en [docs/FLOOT-HANDOFF.md](../docs/FLOOT-HANDOFF.md). El archivo `.sha256` permite comprobar la integridad del paquete. La entrega se revisó contra los archivos fuente y contiene únicamente la configuración pública del cliente; no incluye sesiones, borradores privados ni PDFs personales.

Todavía no se creó una aplicación en Floot: su MCP no expuso herramientas en la conversación que preparó esta entrega. El formato de importación y la posibilidad de publicar una app nativa deben verificarse cuando la integración esté conectada.
