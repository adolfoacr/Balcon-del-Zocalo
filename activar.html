Configuración del propietario · Se hace una vez

Activa las cuentas, el editor y las propuestas.

La web ya está preparada. Estos pasos crean las tablas y permisos en tu proyecto de Supabase. Puedes hacerlos desde Safari en tu iPad; no necesitas descargar archivos.

1. Crea las tablas

Abre tu proyecto, entra en SQL Editor → New query, copia este código completo, pégalo y pulsa Run. El código mantiene privados los trabajos y sus adjuntos y reserva la selección a Checo.

Abrir SQL Editor

2. Configura los correos

En Authentication → URL Configuration, fija Site URL en:

https://adolfoacr.github.io/Balcon-del-Zocalo/

Agrega a Redirect URLs:

https://adolfoacr.github.io/Balcon-del-Zocalo/**

En Authentication → Providers → Email, habilita Email y conserva la confirmación de correo. Para recibir correos de confirmación y recuperación de forma fiable, configura tu SMTP en Authentication; el correo de prueba de Supabase puede limitar destinatarios o envíos.

3. Regístrate y asigna tu cuenta como propietario

Abre la web, toca Registro y confirma tu correo. Después vuelve al SQL Editor y ejecuta la instrucción que generamos abajo. Usa el mismo correo de tu cuenta registrada.

Registrarme en la web

Solo se asigna el primer propietario desde SQL Editor. Registrarse no da acceso al editor.

4. Asigna la cuenta de Checo

Inicia sesión en la web con tu cuenta de propietario. En Administrar → Usuarios y cuenta → Cuenta del chef Checo, indica el correo registrado y confirmado que usará Checo. Si tú también operas su cuenta, puedes asignar tu propio correo.

En Trabajos y colaboración, el equipo puede consultar las propuestas. Checo puede marcar una propuesta en revisión, seleccionarla o responder al participante. El participante consulta la respuesta en Comparte tu trabajo → Mis propuestas.

Abrir la web

La web usa la clave pública que compartiste. No se necesitan claves secret ni service_role.
