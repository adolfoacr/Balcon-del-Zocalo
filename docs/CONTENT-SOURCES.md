# Inventario de contenido

La meta es construir la experiencia gastronómica de Balcón del Zócalo con Noticias, Recetario y un visualizador del Libro. Este inventario permite reemplazar la muestra sin perder la procedencia.

| ID | Procedencia actual | Estado | Información pendiente |
| --- | --- | --- | --- |
| `pilot-experience` | Texto editorial creado para el piloto | Demo | Reemplazar o complementar con una noticia oficial fechada y su URL |
| `pilot-book` | Texto editorial creado para el piloto | Demo | El propietario entregará el libro |
| `fideo-seco` | `RecipeBookView.swift` proporcionado por el propietario | Pendiente | Nombre, categoría e ingredientes confirmados; cantidades, pasos, porciones y tiempos si se ofrece una receta completa |
| `sope-totoaba` | `RecipeBookView.swift` proporcionado por el propietario | Pendiente | Nombre, categoría, ingredientes y procedencia confirmados; receta completa si está disponible |
| Libro | Aún no entregado | Pendiente del propietario | PDF o formato original, portada, edición e índice |

No se conservan las afirmaciones de premios, lanzamientos, capítulos ni cantidades de páginas del ejemplo original: no venían acompañadas de una fuente.

Para considerar una entrada verificada, registrar una fuente confirmada con URL HTTPS y fecha cuando corresponda. `sourceURL` permanece vacío mientras no haya evidencia. El sitio oficial se consultó para los recursos visuales de la renovación. Los ingredientes y la preparación de estas fichas siguen pendientes de cotejo. Ver `DESIGN-REFERENCE.md`.
